# 関数仕様書

対象プログラム: `MatchstickPuzzles.py`

## 1. `matchsticks_for_number`

### 目的

整数を7セグメント表示のマッチ棒表現へ変換する。

### 入力

- `number`: `int`
- `0`以上`99`以下の整数を想定する。

### 出力

- `frozenset[tuple[int, str]]`
- タプルは`(数字の位置, セグメント名)`で表す。
- 数字の位置は、左端を`0`とする。

### アルゴリズム

1. 整数を文字列へ変換する。
2. 各桁について、`DIGITS`から使用するセグメント集合を取得する。
3. 桁位置とセグメント名の組を集合へ追加する。
4. 重複しない不変集合として返す。

## 2. `matchsticks_for_expression`

### 目的

式全体のマッチ棒配置を、位置を区別した集合として作成する。

### 入力

- `left`: 左辺の左側の整数
- `operator`: `+`、`-`、`*`のいずれか
- `right`: 左辺の右側の整数
- `result`: 等号の右側の整数

### 出力

- 式中の数字、演算子、等号に対応するマッチ棒の不変集合。
- 各要素は`(配置位置, マッチ棒識別子)`で表す。

### アルゴリズム

1. `left`、`right`、`result`を`matchsticks_for_number`で変換する。
2. 数字ごとに`left`、`right`、`result`の配置位置を付加する。
3. `OPERATORS`から演算子のマッチ棒を追加する。
4. `EQUALS`から等号のマッチ棒を追加する。
5. すべてを1つの不変集合として返す。

## 3. `is_correct_equation`

### 目的

指定された式が、通常の四則演算として正しいか判定する。

### 入力

- `left`: 左辺の左側の整数
- `operator`: `+`、`-`、`*`のいずれか
- `right`: 左辺の右側の整数
- `result`: 等号の右側の整数

### 出力

- `bool`
- 加算、減算、乗算のいずれかが成立する場合は`True`。
- それ以外は`False`。

### アルゴリズム

1. 演算子が`+`なら、`left + right == result`を判定する。
2. 演算子が`-`なら、`left - right == result`を判定する。
3. 演算子が`*`なら、`left * right == result`を判定する。
4. 上記のいずれかが成立した結果を返す。

## 4. `is_two_move_special_transformation`

### 目的

`7`または`4`を`11`へ、マッチ棒2本の移動で変形する特殊ルールに該当するか判定する。

### 入力

- `left`, `operator`, `right`, `result`: 変形前の式
- `new_left`, `new_operator`, `new_right`, `new_result`: 変形後の候補式

### 出力

- `bool`
- 特殊変形に該当する場合は`True`。

### アルゴリズム

1. 演算子と結果が変形前後で同じか確認する。
2. 変形後の式が通常の四則演算として正しいか確認する。
3. 左辺左側について、`7 -> 11`または`4 -> 11`であり、右側の数値が変わっていないか確認する。
4. 左辺右側について、`7 -> 11`または`4 -> 11`であり、左側の数値が変わっていないか確認する。
5. いずれかを満たす場合に`True`を返す。

## 5. `find_solutions`

### 目的

入力された誤った式から、マッチ棒を移動して成立する式をすべて検索する。

### 入力

- `left`: 入力式の左辺左側の整数
- `operator`: 入力式の演算子
- `right`: 入力式の左辺右側の整数
- `result`: 入力式の結果

### 出力

- 解となる式の文字列リスト。
- 通常の解はマッチ棒1本の移動で成立する。
- `7`または`4`を`11`へ変形する特殊解はマッチ棒2本の移動で成立する。
- 演算子と等号を入れ替える変形にも対応する。

### アルゴリズム

1. 入力式を`matchsticks_for_expression`でマッチ棒集合へ変換する。
2. 演算子が`-`で、`left == right - result`を満たす場合、演算子と等号を入れ替えた式を追加する。
3. `left`、`right`、`result`をそれぞれ`0`から`99`まで全探索する。
4. 各数値の組み合わせに対して、演算子`+`、`-`、`*`を全探索する。
5. 候補式が通常の正しい式か、特殊変形に該当するか判定する。
6. 候補式をマッチ棒集合へ変換する。
7. 元の集合との差分を計算する。
8. 取り外されたマッチ棒が1本、追加されたマッチ棒が1本なら、通常の1本移動の解として追加する。
9. 特殊変形に該当し、取り外されたマッチ棒が2本、追加されたマッチ棒が2本の場合は、特殊解として追加する。
10. 同じ文字列の解を重複して追加しない。
11. 解のリストを返す。

## 6. `is_reordered_equation`

### 目的

`left - right = result`の演算子と等号を入れ替え、`left = right - result`として成立するか判定する。

### アルゴリズム

1. 演算子が`-`であることを確認する。
2. `left == right - result`を確認する。
3. 両方を満たす場合に`True`を返す。

## 7. `find_problems`

### 目的

入力された正しい式を1本のマッチ棒移動（特殊変形を含む）で解にできる、数学的に誤った問題式を検索する。

### 入力

- `left`, `operator`, `right`, `result`: 入力された正しい式

### 出力

- 問題式の文字列リスト。
- 通常の問題式はマッチ棒1本の移動で入力式になる。
- `7`または`4`を`11`へ変形する特殊問題式はマッチ棒2本の移動で入力式になる。

### 仕様

1. `left`、`right`、`result`をそれぞれ`0`から`99`まで、演算子を`+`、`-`、`*`で全探索する。
2. 数学的に誤った候補だけを対象に、入力式とのマッチ棒集合の差分を計算する。
3. 取り外しと追加がそれぞれ1本、または特殊変形でそれぞれ2本の場合に問題式へ追加する。

## 8. `parse_expression`

### 目的

端末から入力された式の形式・値・初期状態を検証し、各要素へ分解する。

### 入力

- `expression`: 端末から入力された文字列

### 出力

- `(left, operator, right, result)`のタプル。

### アルゴリズム

1. `INPUT_PATTERN`で、`x [+-*] y = z`形式に一致するか確認する。
2. 一致しない場合は`ValueError`を発生させる。
3. 数値部分を整数へ変換する。
4. 各数値が`0`以上`99`以下か確認する。
5. 範囲外の場合は`ValueError`を発生させる。
6. 検証済みの値をタプルで返す。

## 9. `main`

### 目的

端末入力、入力エラー時の再入力、解の検索、結果表示、終了処理を制御する。

### アルゴリズム

1. `input`で式または終了コマンドを受け取る。
2. 入力が`q`または`end`（大文字小文字は問わない）の場合、終了する。
3. `parse_expression`で式を検証する。
4. `ValueError`が発生した場合はエラーメッセージを表示し、再入力する。
5. `EOFError`または`KeyboardInterrupt`の場合は終了する。
6. 入力が数学的に正しい場合は`find_problems`で、その式を解とする問題式を検索する。
7. 入力が数学的に誤っている場合は`find_solutions`で解を検索する。
8. 検索結果を1行ずつ表示する。
9. 該当する式がない場合は、その旨を表示する。
10. 1回の式処理後も終了せず、次の入力を受け付ける。
